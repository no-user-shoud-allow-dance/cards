Es gibt zwei Arten, einen Stapel anzusehen:

- **Übersicht** — du siehst alle Karten auf einmal, Vorderseite und Rückseite. Bewerten tust du hier nicht; der Lernfortschritt bleibt unangetastet.
- **Lernmodus** — du gehst die Karten einzeln durch, siehst zuerst die Vorderseite und drehst um, um die Antwort zu sehen. Dann bewertest du, wie gut du die Karte kanntest.

## Das Leitner-System

Beim Bewerten landet jede Karte in einer von **6 Boxen**:

- Kannst du die Karte, wandert sie eine Box weiter — von Box I bis Box VI.
- Eine Karte in Box VI gilt als **gelernt**.
- War die Antwort falsch, wandert die Karte zurück in Box I und erscheint automatisch öfter.

So wiederholst du genau die Karten, die du noch nicht sicher kannst.

## Timer und Pausen

Im Lernmodus läuft optional ein **Timer**, der nur die aktive Lernzeit zählt. Nach jeder Session folgt eine Pause — ein Sechstel der Session-Dauer. Mit einem Doppelklick auf die Pausen-Schaltfläche überspringst du sie. Am Ende einer Session gibt es eine Zusammenfassung.

## Fortschritt zurücksetzen

Ist ein Stapel komplett gelernt, kannst du den Fortschritt zurücksetzen und von vorne beginnen.
